📜Grammar reminder: past and mixed conditionalsClick to openClick here to close this panel
All three patterns describe an imaginary past: something that did not happen. Notice what changes in the result clause.

Third conditional

If + had + past participle, would / could / might have + past participle

If the crew had listened, the ship might not have sunk.

Mixed conditional

If + had + past participle, would + base form (now)

If Fleming had tidied his lab, medicine would be different today.

Inversion (formal)

Had + subject + past participle, … would have + past participle

Had the library survived, historians could have read lost works.
